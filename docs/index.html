CleaNotes Source on GitHub ↗

One focused workspace for writing, organizing, and reviewing notes.

CleaNotes is a local-first desktop note app: a structured notes browser, a rich Markdown editor, sketch annotations, and study cards, in one app. Your notes stay on your device.

Folder-based organization

Nest notes in folders, rename and move entries with drag and drop, and keep everything structured your way.

Rich Markdown editing

A full formatting toolbar built on Milkdown, with support for tables, code blocks, and more.

Sketch mode

Draw and annotate directly on a note, alongside your written content.

Study mode

Turn compatible Markdown lines into flashcards or multiple-choice questions for quick review.

Multi-window support

Duplicate a note into its own window, with autosave keeping every window in sync.

Global search

Search across every note instantly, with customizable theme, accent, and layout to match your taste.

Always up to date

CleaNotes checks for new releases in the background and can install them without a re-download — just review the changes and restart when you're ready. New releases are always available here too.
